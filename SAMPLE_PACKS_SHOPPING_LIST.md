## NAMING CONVENTION (CRITICAL)

For **melodic samples** (808s, leads, pads, bass), the filename determines the pitch:

| Filename | MIDI Note | Frequency |
|----------|-----------|-----------|
| `808_C.wav` | 48 (C3) | 130.81 Hz |
| `808_C1.wav` | 36 (C1) | 65.41 Hz |
| `808_F#.wav` | 54 (F#3) | 185.00 Hz |
| `808_A#2.wav` | 58 (A#3) | 233.08 Hz |
| `lead_C.wav` | 60 (C4) | 261.63 Hz |
| `lead_A3.wav` | 57 (A3) | 220.00 Hz |
| `bass_G2.wav` | 43 (G2) | 97.99 Hz |

**Drums** (kicks, snares, hats) don't need note names:
- `kick_01.wav`, `snare_hard.wav`, `hihat_closed_03.wav`
